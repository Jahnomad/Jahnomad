# Затерянные в Реутове — JAH NOMAD

**Sprint 0** — стартовая заставка, русское меню и вступление. Оригинальный Unity 6 / C# проект (без сторонних коммерческих игровых ресурсов).

## Проверенный комплект для следующей облачной сборки

- `Assets/Scenes/00_Boot.unity` — физическая сцена, находящаяся в GitHub, с постоянным GUID.
- `Assets/Scenes/00_Boot.unity.meta` — метаданные сцены.
- `ProjectSettings/EditorBuildSettings.asset` — включённая стартовая сцена.
- `Assets/Scripts/Core/BootFlowController.cs` — самостоятельная инициализация при загрузке сцены, заставка, меню, настройки, навигация и WebGL-уведомление о выходе.
- `Assets/Scripts/Core/ReutovRuntimeArt.cs` — оригинальные процедурные пиксельные изображения фона Реутова и русского меню, создаваемые в самой игре при отсутствии PNG. Не зависит от импорта в редакторе.
- `Assets/Editor/ReutovAssetImporter.cs` — настройки импорта будущих статических PNG.
- `Packages/manifest.json` — UGUI, Audio, ImageConversion.
- `ProjectSettings/ProjectVersion.txt` — Unity 6000.0.58f2.
- `tools/validate_unity.py` + `.github/workflows/unity-source-check.yml` — независимый предсборочный контроль.

## Первый игровой эпизод — «Комендантский час»

**Новая игра → Во двор.** Миша встречает Регину, находит две батарейки в
«Москвиче», забирает дневник брата у гаражей, показывает его Регине и
укрывается в подъезде. Последний диалог завершает эпизод; «Назад» возвращает
в меню, новая игра начинает эпизод заново. Прогресс задания не сохраняется.

- ПК: WASD / стрелки — движение, Shift — бег, E / пробел — действие и диалог,
  F — фонарь, Escape — меню.
- Телефон: джойстик, удержание «Бег», «Действие», «Свет»; диалог также
  перелистывается нажатием на панель.
- Мерцающая метка указывает текущую цель. Фонарь включается после получения
  батареек. Попадание в луч патруля возвращает к началу двора, сохраняя
  выполненные шаги задания. Во время диалога движение и обнаружение отключены.
- Двор, персонажи и интерфейс используют прежние процедурные пиксельные
  изображения. Поле и кнопки вместе вписываются в 16:9 без растяжения мира.

Проверки: `python3 tools/validate_unity.py` (нужны tree-sitter и
 tree-sitter-c-sharp) и `python3 -m unittest discover -s tests -v`.
Проверки маршрутов и шрифта не заменяют запуск в Unity. Для этой версии
нужна новая сборка Unity 6000.0.58f2: ZIP в `webgl-upload/` содержит прежний
скомпилированный код и автоматически от изменения C# не обновляется.
