# Затерянные в Реутове

Игра JAH NOMAD — оригинальный Unity-проект на C#.

**Sprint 0:** заставка JAH NOMAD, титульный экран и русское меню.

Проект подготавливается к сборке в Unity Build Automation (Web и Android).

Исходники предназначены для собственного проекта. Сторонние коммерческие APK и ресурсы в репозиторий не включаются.

> Статус: исходный проект, первая облачная сборка ещё не подтверждена.
