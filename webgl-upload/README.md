# Загрузка собранной Unity WebGL игры

Поместите сюда **один ZIP-архив** готовой сборки Unity Cloud (например, `1376010984342-reutov-reutov-webgl-test-3.zip`).

GitHub Actions автоматически распакует ZIP, распакует вложенные `.gz` файлы и опубликует браузерную версию.

Требуется один раз включить **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Не загружайте APK, чужие игровые ассеты, приватные ключи или токены.
